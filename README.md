# ITM Cutter

Independent Android controller for the PT005/CUTTER_E66F plotter.

- App name: **ITM Cutter**
- Package: `pt.itm.cutter`
- Bluetooth Classic SPP transport
- OEM catalogue UI flow: category -> family/brand -> model -> cut
- Direct SJC download and transmission to the user's cutter

The catalogue client only uses catalogue endpoints that respond without private credentials. It does not call credit/redeem/use-count endpoints.
